# 2027 정미년 신년운세 · 재물·취업 특화 사주 리포트 (MVP)

2027년(정미년) 신년운세 사주 웹 서비스의 **동작하는 로컬 프로토타입**입니다.
빌드 도구·외부 라이브러리 없이 정적 파일만으로 돌아갑니다.

- 무료 구간: 사주 원국표 4기둥, 오행 밸런스, 2027 핵심 키워드 3개, 일간 성향, 2027 정미년×일간 조합 해석, 대운 타임라인
- 유료(잠금) 구간: 히어로 총평(3대 지수 게이지), 2027 재물운(현금흐름·부업/투자 타이밍·조심할 시기), 2027 취업·이직·진로운, 2027 개운 처방, 12개월 로드맵(배지·점수 바)
- 대운(大運): 양남음녀 순행·음남양녀 역행, 대운수(절입까지 일수÷3 반올림, 절기만 기준) → 10개 기둥 타임라인, 2027 현재 대운 하이라이트
- 개운 처방: 용신·희신 오행 + 행운 색·방향·숫자·일상 처방·직무 키워드
- 공유: 결과 링크 복사(URL 해시 #b=…&g=…&s=…로 재열람), 한 줄 요약 복사, Canvas 1080×1350 PNG 카드
- 페이월 UX: 잠금 상태 블러 처리 + "체험용 잠금 해제(₩3,900 상당 무료 미리보기)" 버튼으로 결제 없이 전체 열람 → 실제 결제 연동 지점만 비워 둔 구조

## 실행

```bash
cd projects/saju-2027
python3 -m http.server 8000      # http://localhost:8000
```

정적 파일이라 파일을 직접 열어도 되지만, 로컬 서버로 여는 쪽이 안전합니다.
서버·계정·DB가 필요 없고, 입력값은 브라우저 메모리(localStorage)에만 남습니다.

## 계산 로직

| 항목 | 방법 |
| --- | --- |
| 년주 | **입춘(태양황경 315°)** 시각을 기준으로 연도 경계 결정, 1984 갑자년 기준 60갑자 인덱스 |
| 월주 | 출생 시점의 태양 황경으로 절기월 판정 (315°=인월, 30° 간격), 월간은 연간에서 유도 |
| 일주 | 율리우스일 + 49 (mod 60) — 1998-05-08 = 乙卯 등 공개 만세력과 대조 완료 |
| 시주 | 12시진(자시 23:00~01:00), 일간에 따른 자시 천간 + 시진 오프셋 |
| 절기 | 태양 겉보기 황경을 뉴턴 반복으로 계산 (Meeus 저정밀 태양좌표 + ΔT). 발표값 대비 ±10분 이내, 날짜는 2027년 24절기 전부 일치 |
| 음양력 | 한국천문연구원 음양력 데이터를 1900~2049년 테이블로 생성해 사용 (윤달 포함) |
| 십성·오행 | 천간 10자·지지 본기 기준 십성, 지장간(여기·중기·본기) 표기, 글자 수 기준 오행 비율 |
| 신강·신약 | 월령 가중치를 준 오행 점수로 비겁+인성 vs 식상+재성+관성 비율 판정 |
| 세운 | 2027 丁未의 천간·지지 십성, 원국과의 합·충·형·파·해, 일간 기준 십이운성 |
| 대운 | 양남음녀 순행·음남양녀 역행, 대운수 = 절입까지 일수÷3(반올림, 24절기 중 절 기준), 월주에서 1간지씩 이동한 10개 기둥, 나이는 만 나이 기준 |
| 월운 | 2027년 각 달 15일 기준으로 절기월·월주를 계산해 재물/취업 점수와 문장 생성 |

일주는 **자정(00:00) 기준**으로 바뀝니다(조자시설). 23:00~24:00 출생은 관법에 따라 하루 차이가 날 수 있어 화면 하단에 명시했습니다.

## 검증

```bash
cd projects/saju-2027
python3 tests/run_tests.py      # → 71 / 71 통과
python3 tests/robustness.py     # → 11개 케이스 전부 정상(해시 공유 진입 포함), 콘솔 오류 0
python3 tools/check_terms.py    # → 24절기 발표값 대조
```

검증·캡처 스크립트는 Playwright(headless chromium)를 씁니다. 이 작업 환경에서는
`/workspace/.pw-browsers`(브라우저)와 `/workspace/.pw-libs`(ATK 계열 라이브러리)에 설치해 두었고,
스크립트가 `PLAYWRIGHT_BROWSERS_PATH`·`LD_LIBRARY_PATH` 기본값으로 잡습니다.
다른 환경에서는 `python3 -m pip install playwright && python3 -m playwright install chromium`
 후 환경변수를 빼면 됩니다.

검증에 포함된 대조값(공개 만세력·한국천문연구원 기준):

- 1998-05-08 12:00 → **戊寅 丁巳 乙卯 壬午** (음력 1998.4.13, 입하 5/6 02:03 경과)
- 1998-05-05 → 월주 丙辰 / 1998-05-07 → 丁巳 (입하 절입 경계)
- 1998-02-03 → 년주 丁丑 / 1998-02-05 → 戊寅 (입춘 경계)
- 2000-01-01 자시 → 己卯 丙子 戊午 壬子
- 일진: 1998-05-06 癸丑, 1998-05-31 戊寅, 2026-11-16 甲午, 2027-01-01 庚辰, 2027-02-07 丁巳, 2027-05-06 乙酉
- 2027년 24절기 24건 날짜 전부 일치(예: 입춘 2/4, 상강 10/24, 동지 12/22)
- 음↔양 왕복 변환 500건 불일치 0건
- 대운: 양남 순행(1998-05-08 남, 대운수 10·戊午 起), 양녀 역행(같은 날 여, 대운수 1·丙辰 起),
  음녀 순행(2000-01-01 여, 대운수 1·丁丑 起), 음녀 순행(1997-08-15 여, 대운수 8·己酉 起),
  2027 현재 대운 하이라이트(만 나이 기준) — 대운수는 24절기 중 절(立春·경칩 등) 기준

## 알려진 한계 / 다음 단계

1. **결제 없음** — "체험용 잠금 해제"는 UX 확인용 토글입니다. 실제 서비스에는 결제(PG)·주문 저장·재열람 링크가 필요합니다.
2. **절기 시각 정밀도** ±10분 — 저정밀 태양좌표식을 사용했습니다. 절입 경계에 아주 가까운 출생(수 분 차)은 만세력에 따라 월주·대운수가 달라질 수 있습니다. 실제 서비스에서는 VSOP87 수준 계산이나 KASI 절기표를 쓰는 편이 좋습니다.
3. **대운 나이는 만 나이 단순 기준** — 2027 − 출생연도로 계산합니다(생일 지나기 전 날짜는 1살 차이 가능). 대운수도 반올림 관례(÷3 반올림)를 따르므로 만세력에 따라 ±1 차이가 있을 수 있습니다.
4. **용신 판정은 신강약 기반 단순 규칙** — 신강→식상, 중화→관성, 신약→인성을 용신으로 삼는 휴리스틱입니다. 조후·조후법·격국을 반영한 정밀 용신은 다음 단계 과제입니다.
5. **해석 문장은 규칙 기반** — 일간·오행·십성·세운 조합 규칙으로 조립합니다. 월별 문장은 25조합×3변형+계절·합충 덧붙임으로 중복을 제거했습니다.
6. **공유 링크는 입력값을 URL 해시에 담습니다** — 이름을 입력하면 해시에도 포함됩니다(로컬 계산·로컬 조각이라 서버 전송은 없음). 실제 서비스에서는 짧은 ID + 서버 저장 방식을 권합니다.
7. **표준시 고정** — 1908년 이전 출생도 현재 표준시(UTC+9)로 계산합니다(당시 한국 표준시는 +8:30). 실제 서비스에서는 출생 연도별 표준시·경도 보정 옵션이 필요합니다.
8. **월운 점수는 규칙 기반 휴리스틱** — 재성/관성 월에 가점을 주는 단순 모델이라, “합격운 강한 달”과 “조심할 달”이 같은 달에 겹칠 수 있습니다(예: 관성이 강하지만 원국과 충이 걸리는 달). 배지·문장은 이 경우를 분리해 표현합니다.
